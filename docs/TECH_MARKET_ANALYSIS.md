# 敏感词审核技术行业分析

## 一、传统方案（目前仍广泛使用）

### 1. 关键词/正则匹配

```
简单字符串匹配，O(n×m) 复杂度
```

- **代表技术**：DFA、AC 自动机
- **优点**：速度快、精确匹配
- **缺点**：无法识别变体（谐音字、表情符号）
- **企业现状**：中小型平台仍大量使用

### 2. 词库扩展 + 规则引擎

```
关键词库 + 自定义规则（正则、位置权重）
```

- **代表产品**：阿里云内容审核、腾讯云文本内容安全
- **优点**：规则可配置、词库更新快
- **缺点**：维护成本高、误报率高

---

## 二、现代方案（主流趋势）

### 1. 规则 + 语义向量

```
关键词匹配 + 向量相似度检索
```

- **代表技术**：pgvector、Milvus、Qdrant
- **优点**：识别变体、理解语义
- **缺点**：向量维度选择影响精度

### 2. 规则 + 向量 + LLM

```
三层漏斗：精确匹配 → 语义检索 → 推理判断
```

- **代表产品**：OpenAI Moderation API、Jetwash
- **优点**：覆盖全面、准确率高
- **缺点**：成本较高、延迟增加

```
传统方案（关键词） → 向量方案（语义） → LLM方案（智能）
```

## 六、Jetwash 在行业中的位置

Jetwash 采用**三层漏斗架构**，结合了传统方案的速度优势和 LLM 方案的智能优势：

```
Layer 1 (速度)     → AC自动机精确匹配，毫秒级响应
Layer 2 (语义)     → pgvector向量检索，识别变体威胁
Layer 3 (智能)     → LLM推理判断，处理复杂语境
```

**核心差异**：
- 多层防护：每层各司其职，相互补位
- 自动学习：LLM 发现的新词自动入库，减少人工维护
- 多租户隔离：企业级数据安全

## 七、选型建议

| 场景 | 推荐方案 | 原因 |
|------|----------|------|
| **初创公司/个人项目** | 关键词/正则 | 成本低、快速上线 |
| **成长型平台** | AC自动机+向量 | 性价比高，能识别变体 |
| **中大型企业** | Jetwash/云厂商 | 功能全面，运维成本低 |
| **高合规要求（金融/政府）** | 云厂商+私有化部署 | 符合监管，数据不出门 |

## 八、未来趋势

1. **多模态融合**：文本+图片+音频+视频一体化审核

3. **成本优化**：LLM 量化压缩，边端部署
4. **行业垂直化**：金融、医疗、教育等垂直场景定制
5. **自动化运营**： AutoML 自动优化审核模型
